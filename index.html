Diccionario Traductor

Traducción de palabras del español a lengua materna

Bienvenido

Este proyecto tiene como objetivo crear un diccionario traductor que permita consultar palabras en español y visualizar su traducción en lengua materna.

El sistema será desarrollado de forma colaborativa usando Git, GitHub, issues, ramas, Pull Request y un tablero Kanban.

¿Cómo usar el diccionario?

Para utilizar el diccionario, el usuario debe escribir una palabra en español. El sistema mostrará la traducción en lengua materna si la palabra se encuentra registrada.

Este proyecto busca apoyar la consulta, conservación y valoración de la lengua materna mediante una herramienta sencilla y fácil de usar.
